# Cedar Grove Academy — Informational School Website

An original, multi-page, frontend-only school information website created for a portfolio project. The school, staff, address, events and contact details are fictional sample content.

## Pages
- Home (`index.html`)
- About Us (`about.html`)
- Academics (`academics.html`)
- Admissions (`admissions.html`)
- Facilities (`facilities.html`)
- Our Staff (`staff.html`)
- News & Events (`news.html`)
- Gallery (`gallery.html`)
- Contact (`contact.html`)

## Technology
HTML5, CSS3, JavaScript, Bootstrap 5 and Tailwind CSS (CDN). No backend or database is used.

## Run the website
1. Extract the ZIP file.
2. Open the `cedar-grove-academy` folder in Visual Studio Code.
3. Open `index.html` with the Live Server extension, or open the file in a browser.
4. An internet connection is required for Bootstrap, Tailwind, Google Fonts and the Unsplash images.

## Frontend-only behaviour
The contact form validates the fields and saves demo enquiries in the current browser using `localStorage`. It does not send an email or share submissions with anyone. The school details, people, photos and news are illustrative portfolio content, not real school records.
